# Календарь звонков

Сервис бронирования звонков: владелец календаря создаёт типы событий, гость выбирает тип события и свободный слот в ближайшие 14 дней и создаёт бронирование. Регистрации и авторизации нет.

## Язык

**Владелец**:
Единственный заранее заданный хозяин календаря, который создаёт типы событий и видит предстоящие звонки.
_Avoid_: Админ, администратор, хост, организатор

**Админка**:
Раздел сервиса, в котором владелец создаёт типы событий и видит предстоящие звонки.
_Avoid_: Админ-панель, личный кабинет, дашборд

**Гость**:
Человек, который без аккаунта и входа в систему выбирает тип события и бронирует слот, оставляя только имя. Имя не уникально и гостя не идентифицирует.
_Avoid_: Клиент, посетитель, пользователь, участник

**Тип события**:
Вид звонка, который владелец предлагает гостям; у него есть название, описание и длительность в минутах. Название уникально среди типов событий (без учёта регистра). Длительность кратна шагу сетки слотов и не превышает 8 часов.
_Avoid_: Вид брони, услуга, тариф

**Окно записи**:
Период в 14 календарных дат по московскому времени (сегодня и 13 следующих), в пределах которого формируются слоты. Слот входит в окно по моменту своего начала.
_Avoid_: Горизонт, диапазон

**Слот**:
Свободное для выбранного типа события начало звонка на сетке слотов в окне записи. Длительность берётся из типа события, поэтому одно и то же время может быть свободно для короткого типа и занято для длинного. Отдельного идентификатора у слота нет. Слот на сегодня существует, только если его начало строго позже текущего момента.
_Avoid_: Интервал, время

**Сетка слотов**:
Шаг в 15 минут, с которого по московскому времени начинаются слоты; общий для всех типов событий.
_Avoid_: Шаг, расписание

**Бронирование**:
Занятие гостем слота под выбранный тип события: хранит начало звонка и имя гостя. Занимает интервал от начала на длительность типа события. Два бронирования не могут пересекаться по времени, даже если типы событий разные; «встык» (конец одного равен началу другого) разрешён.
_Avoid_: Запись, бронь, заявка

**Звонок**:
Сам разговор между владельцем и гостем, назначенный через бронирование; единственное слово для него в интерфейсе.
_Avoid_: Встреча, созвон, митинг

**Предстоящий звонок**:
Звонок, который ещё не закончился: его конец строго позже текущего момента, поэтому идущий сейчас звонок тоже предстоящий. Завершённых звонков владелец не видит.
_Avoid_: Будущий звонок, ближайший звонок
