# Календарь звонков

Сервис бронирования времени для звонков: админ публикует доступное время, гость выбирает свободный слот и записывается на звонок. Авторизации и личных кабинетов нет.

## Язык

**Админ**:
Единственный хозяин календаря, который публикует доступное время и видит предстоящие звонки.
_Avoid_: Владелец, администратор, хост, организатор

**Админка**:
Раздел сервиса, в котором админ видит предстоящие звонки.
_Avoid_: Админ-панель, личный кабинет, дашборд

**Гость**:
Человек, который выбирает свободный слот и записывается на звонок.
_Avoid_: Клиент, посетитель, пользователь, участник

**Слот**:
Свободный 30-минутный интервал времени, на который можно записаться.
_Avoid_: Окно, интервал, время

**Запись**:
Слот, занятый гостем.
_Avoid_: Бронь, бронирование, заявка

**Звонок**:
Сам разговор между админом и гостем, назначенный через запись; единственное слово для него в интерфейсе.
_Avoid_: Встреча, созвон, митинг
