# Календарь звонков

Сервис бронирования времени для звонков: владелец публикует доступное время, гость выбирает свободный слот и записывается на звонок. Авторизации и личных кабинетов нет.

## Язык

**Владелец**:
Единственный хозяин календаря, который публикует доступное время и видит предстоящие звонки.
_Avoid_: Хост, администратор, организатор

**Гость**:
Человек, который выбирает свободный слот и записывается на звонок.
_Avoid_: Клиент, посетитель, пользователь, участник

**Слот**:
Свободный 30-минутный интервал времени, на который можно записаться.
_Avoid_: Окно, интервал, время

**Запись**:
Слот, занятый гостем.
_Avoid_: Бронь, бронирование, заявка

**Звонок**:
Сам разговор между владельцем и гостем, назначенный через запись; единственное слово для него в интерфейсе.
_Avoid_: Встреча, созвон, митинг
